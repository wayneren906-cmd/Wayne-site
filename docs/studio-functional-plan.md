- Studio 保留摄影与柔和标题入场，取消概览/详情重复导航，四段特稿提供段内目录。真实共享项目组件可切换容器宽度，使用容器查询重排；辅助网格不修改内容、字体或原图。
- `/search` 使用同一公开内容清单检索项目和手记，按类别/真实主题筛选，显示正文匹配片段。Studio 与 Journal 按实际共有主题关联；没有相关材料时不制造条目。
- 新内容为本地版本化文件，既有 D1 records 兼容读取，公开数据按允许字段投影。没有新迁移、账号系统、搜索服务或依赖；数据库失败不显示成成功的空列表。
- 旧 `/admin`、`/login`、`/studio/private/*` 退出网站浏览；管理写入请求服务端拒绝。外部同步与定时快照保留，未改生产权限或定时配置。

首批不包含历史版本对比、知识图谱、自动整理或新增私人草稿预览。尚未新增真实手记材料，`content/journal.ts` 为空；本地预览使用内存数据库，不导入线上内容。验收命令与结果见工作台验证记录。

## 2026-10-15 当前方向：项目与进展展示

用户认为 Studio 冗杂，并在讨论和试用后不采用“汇总信息 + AI 整理确认”的方向。当前以公开项目及进展展示为主，减少入口；不继续增加缺乏实际用途的管理或智能化流程。

- 公开导航仅保留项目概览、项目详情；学习手记回到 Journal。旧学习、练习、档案路由保留以兼容原链接，不再放在主导航。
- 首页仅查询已发布项目快照，展示项目名称、本人确认的状态、进展、可选下一步及详情链接。未发布目录与蓝图不填充公开项目列表；空列表和读取失败分别展示。
- 详情只展示已发布项目，阶段状态与参考标准按需展开。参考标准不等于已有成果；公开页不提供私人记录操作按钮。
- 首页移除学习统计、重复手记、目标、连接状态和多项后台操作入口；摄影、字体、主题和已有动效保留。
- 私人记录、项目和目标管理及发布规则保持。没有新增 AI 整理、自动汇总、任务执行、自定义项目或数据迁移；公开展示与后台能力分开。

## 在 Wayneo 中的角色

Index、Journal、Studio 均可公开浏览，共同构成个人数字空间。Index 提供个人介绍与探索入口；Journal 承载公开手记与时间线；Studio 是成长、学习、项目、创作和数字活动的数据展示与管理中心。

## 私人工作台与系统总览

`/studio/private/management` 作为私人工作台，提供新增记录、更新项目和管理目标入口，展示已保存的当前目标、进行中的项目、待发布变化及本次快照中最近 5 条记录。目标、项目、记录和系统提醒独立读取；读取失败显示对应错误，不替换成空数据。待发布变化仅比较公开字段，不包含私人备注或其他页面中尚未保存的输入。

`/studio/private/system` 承接系统状态与账号管理，沿用只读 `GET /api/studio/management`。总览读取现有私人表，展示私人记录数量、现存接收回执、数据版本、来源摘要与后台任务状态；近期任务最多 20 条，支持筛选和手动刷新。统计包含当前账户未删除记录关联的历史修订任务，并明确区分当前版本与历史版本。来源的最近接收时间包括修订，接收时间不当作学习时间。账号添加仍仅限首位管理员。

私人栏目统一为工作台、私人记录、项目管理、目标管理、系统与账号。`/studio/private/workspace` 保留原有链接及练习、项目、里程碑参数，作为统一新增记录页；无参数默认日常记录。记录页不再提供第二套内嵌新增表单。学习日期可选，协助程度与执行方式收在补充信息中。日常记录沿用原补充记录的来源语义，关联记录沿用已有来源编号约定，不迁移数据模型。保存后可查看记录，或继续更新同一项目的里程碑；保存过程记录不自动改变项目状态。

项目管理页展示当前快照中的里程碑过程记录，明确数量不是全部历史或验收结论。项目与目标发布预览展示旧公开版本与已保存草稿的字段变化；目标预览包括移除与顺序变化，整份目标列表仍由本人确认发布。

本批为本地实现：208 项测试、类型检查、隔离完整构建、Worker 权限检查及合成浏览器流程通过。没有生产部署或远程数据库迁移。完整记录分页检索、自定义项目与独立关联关系仍待后续实现。

权限与内容在同一次 D1 batch 中核对，接口仅限经过验证且仍启用的所有者，集成读取 scope 不提供管理权限。响应不包含私人正文、任意来源字符串、原始错误、幂等键或凭证信息，私人页面和 API 禁止共享缓存。刷新失败清除旧数据并显示错误，不把读取失败显示为空数据或健康状态。

任务执行器仍未接入，总览只能显示数据库已有任务状态；不提供假重试或启动按钮，也不由刷新触发任务执行。此批无需迁移或修改 Access 路径，沿用现有私人路径保护。真实所有者登记、生产私人导入与备份配置仍需后续授权和验证。

## 项目进展与发布管理

`/studio/private/projects` 管理项目状态、介绍、进展说明、下一步、里程碑状态与私人备注。本地代码支持三个学习方向及 Wayneo，线上仍为原有三个方向。新草稿不自动公开；保存后预览公开字段，明确确认后才发布。公开仪表盘与项目页仅读取已发布快照。已发布后编辑草稿不改变旧快照；撤下后从公开项目列表移除，私人草稿和未保存输入保留。

`GET/POST /api/studio/projects` 只接受有效且启用的管理员身份，不接受集成 token。操作使用版本比较与幂等回执，草稿/发布状态和回执同批事务提交；撤销权限在数据库写入时再次验证，原发布回执的重放不会重新公开已撤下内容。发布与里程碑状态由管理员确认，不等于自动能力评估或独立实践证明。

`0006_studio_projects.sql` 已随 a44a6ef 在 2026-10-14 获授权上线，生产迁移和公开读取核对通过；原公开手记、快照与学习表不改动。离线加密备份已包含项目草稿、私人备注、发布快照与操作回执；恢复后保持私人状态并推进项目版本，旧发布不会自动复活。生产密钥保管、独立检查点存储、保留策略及定时备份仍待配置。未导入真实项目事实。

## 目标与计划

`/studio/private/plans` 管理一份最多 8 个目标的计划，包括目标名称、状态、说明、下一步、可选目标日期与整份计划的私人备注。状态由本人确认，不计算虚构完成率；目标日期不是实际完成时间。清空或移除目标只改变私人草稿，公开版本需要重新发布或明确撤下。

`GET/POST /api/studio/plans` 使用服务端邮箱会话、版本比较、幂等回执与事务内权限复核。发布预览列出全部公开字段，私人备注始终排除。公开仪表盘读取独立快照，读取失败与暂无公开目标分别展示。`0007_studio_plans.sql` 不填充真实目标。

## 邮箱登录

按用户最新要求，以邮箱密码登录替代旧 Cloudflare Access 登录；网站不要求游客登录。已有管理员拥有私人空间管理权限，首位管理员可添加其他管理员；新管理员管理同一个空间，不自动成为首位管理员。没有公开注册端点。

`0008_email_auth.sql` 新增账号、会话及登录限速表，没有内置密码或账号数据。密码以独立随机盐的 scrypt 哈希保存；浏览器使用 HttpOnly、Secure、SameSite=Strict 会话 Cookie，数据库仅存随机会话令牌的摘要。旧 Access JWT 不授予网站权限，旧登记端点返回 410。上线先验证新登录与私人接口，再移除精确匹配本站路径的旧 Access 应用。
