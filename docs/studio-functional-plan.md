# Wayneo Studio 产品定位

2026-10-14。以本次确认的 Personal Dashboard 定义为准，替代此前仅围绕学习工作台的定位。

Wayneo Studio — A living dashboard of my growth, work, and exploration.
一个持续更新的个人数字仪表盘，让成长可见，让进展可追踪，让一切尽在掌握。

## 在 Wayneo 中的角色

Index、Journal、Studio 均可公开浏览，共同构成个人数字空间。Index 提供个人介绍与探索入口；Journal 承载公开手记与时间线；Studio 是成长、学习、项目、创作和数字活动的数据展示与管理中心。

## 四个核心能力

| 能力 | 产品职责 | 本次实现与边界 |
| --- | --- | --- |
| 数据可视化 | 展示知识积累、学习活动、项目与创作的长期变化 | 公开 Journal 的月度与累计内容统计，6/12 个月切换和明细；数量不代表能力或完成率 |
| 实时状态 | 呈现当前探索、项目、活动与目标 | 根据最新公开手记展示近期探索、记录日期和活动；项目目前展示蓝图，没有伪造执行状态；目标尚未公开 |
| 内容与数据管理 | 管理记录、日志、项目、计划与发布审核 | 保留私人记录的补充、修订、历史与练习/项目证据管理入口；计划编辑、完整项目编辑与审核发布仍待实现 |
| 智能化与自动化 | 连接 ChatGPT 学习系统、数据库和公开网站，查看同步、任务与异常 | 展示本次公开数据读取结果及真实连接范围；ChatGPT 和自动化监控尚未接入；不能将网站现有定时任务当作已具备监控管理能力 |

Studio 是可视化与操作入口。同步执行、任务调度、权限检查与数据存储由相应服务承担。

## 公开与私人权限

采用公开浏览 + 管理员增强。新事实和原始证据默认私人；公开数据经过明确的发布规则。本次首页只使用现有公开 Journal 和公开项目目录，不读取私人 context 接口。管理员权限继续在服务端验证，前端隐藏按钮不能替代认证。

## 信息结构与设计

设计关键词：Minimal · Editorial · Data-driven · Interactive · Precise。
延续现有全小写 wayneo 字标、字体、纸本/暗室主题和 editorial 变量。首页按成长趋势、近期探索、项目与创作、活动、连接状态组织，保留学习目录与练习作为子能力。桌面使用克制的双栏和项目三栏，手机自然收为单栏。共享页眉在窄屏保持品牌、三项导航和主题按钮同一行。

## 尚待接入

当前记录会随页面读取更新，并非实时推送。后续需建立可审核的公开项目进展、目标与创作模型，接通 ChatGPT 同步回执、自动化任务/异常监控及其管理员操作。没有数据时显示空态、未公开或尚未接入，不能使用模拟统计填充个人仪表盘。
